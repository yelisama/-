# 丛雨神社刮刮乐

穗织丛雨神社委托开发的抽卡收集小游戏插件。10 金币一抽，90 抽保底收藏品，附带投喂和许愿树功能。
如果订阅可根据需求进行修改

## 功能

- **刮刮乐抽奖** — 单抽 / 十连，五档奖项，最高 150 金币
- **收藏品系统** — 10 件丛雨神社限定周边，⭐至⭐⭐⭐三档稀有度，90 抽硬保底
- **投喂系统** — 给夜璃上供零食点心，神社裁定回礼金币
- **许愿树** — 花金币挂愿望，匿名展示所有群友的愿望

## 安装

AstrBot 插件市场搜索"刮刮乐"安装，或将插件文件夹放入 `addons/plugins/`。

## 指令

| 指令 | 说明 |
|------|------|
| `/刮刮乐` | 单抽一次 |
| `/十连` | 十连抽 |
| `/金币` | 查看余额 |
| `/收藏品` | 查看收藏品柜 |
| `/投喂 <物品>` | 投喂夜璃换取金币 |
| `/神社许愿 <内容>` | 写一条愿望挂上许愿树 |
| `/许愿树` | 查看所有人的匿名愿望 |

## 配置

所有参数均可在 AstrBot WebUI 中直接修改，支持滑块调节。

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 单抽金币 | 10 | 每次刮刮乐消耗 |
| 每日上限 | 10 | 非 VIP 用户每日可抽次数 |
| 许愿金币 | 500 | 许愿一次的花费 |
| 保底抽数 | 90 | 累计抽数必出收藏品 |
| 初始金币 | 200 | 新用户首次获得 |
| 投喂开关 | 开 | 关闭后投喂提示暂停 |

## 概率表

| 奖项 | 概率 | 金币范围 |
|------|------|----------|
| ★金光闪闪大奖★ | 1% | 80~150 |
| 二等奖 | 5% | 30~50 |
| 三等奖 | 14% | 15~25 |
| 四等奖 | 30% | 8~14 |
| 参与奖 | 50% | 1~7 |

收藏品额外掉落：参与奖有 0.5% 概率欧皇触发。

## 注意事项

- 每日抽数和投喂次数凌晨 0 点重置
- 保底计数跨天累积
